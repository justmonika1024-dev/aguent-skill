# 凿 agugent 前端

React + TypeScript 的状态机控制台。开发时通过 Vite 代理访问 `http://127.0.0.1:8000/api/v1`，不会读取或保存 LLM/Exa 密钥。

## 从源码启动

前置要求：Node.js 20+、pnpm 11，且后端已在 8000 端口启动。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

访问 `http://127.0.0.1:5173`。

## 评价与连续执行

任务到达“等待人工评价”后，评价页按处理顺序展示七个模块：原梗搜索计划、原梗
选择、变式搜索计划、变式搜索结果、模板提取、候选生成和最终结果。评分项必填，
各模块文本意见、候选修改建议和总体意见均为选填。提交后生成的策略版本可在
“策略版本”页面追溯；连续自主发现的下一轮 N07 会应用上一轮反馈形成的搜索指令。

同一个原梗在 N09/N11 间共享最多 2 次变式补搜机会。后端重启会丢失活动任务的
内存状态；历史节点和评价仍可查看，但不能从等待评价或运行中的位置继续执行。

## 自测

```bash
pnpm lint
pnpm typecheck
pnpm test --run
pnpm build
pnpm exec playwright test
```

端到端测试会拦截 API 请求并使用固定响应，适合验证前端路由与核心交互；真实联调时不要启动 Playwright，直接同时启动前后端。

MVP 前端尚未开放策略激活、正式梗下架和恢复操作，因此相应操作明确显示为禁用态。
