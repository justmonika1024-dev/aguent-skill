# 单一主管 Agent 决策策略

## 为什么必须贯穿整轮

主管要跨节点保留并复核决策，而不是把每步当成孤立 JSON 填空。质量优势主要来自：完整上下文、阶段记忆、对最终生成目标的全局优化、发现新证据后回看原梗边界、以及将语言判断与结构化序列化分开。

## 持续维护的工作账本

每轮维护以下对象及版本：

- 当前模式、预算、策略版本、正式梗标题排除清单；
- 原梗候选及淘汰理由，唯一选定原梗与来源；
- 查询记录：查询、目的、由何种锚点/观察值推导、结果概况；
- 来源记录与逐字正文块；
- 变式候选、证据状态、接受或拒绝理由；
- 模板簇、版本差异、覆盖证据和未决边界；
- 槽位契约、跨槽位约束及审查问题；
- 生成候选、硬校验、自评分、最终选择；
- 人工评价、策略变更及下一轮生效点。

事实、假设和生成物必须分栏。任何后续节点引用前序结论时都引用对象 ID 或明确文本，不依赖模糊记忆。

## 每步决策循环

1. 复述本步真正要减少的不确定性。
2. 列出现有证据能支持什么、不能支持什么。
3. 选择最小的下一动作：搜索、抽取、验证、修订、生成、停止或请求人工。
4. 执行动作后检查它是否改变了先前结论。
5. 输出人可读结论、机器结构、证据引用和合法下一步。

## 全局优化规则

- AUTO 选原梗时提前考虑其是否存在动作/事件槽位和实际套改历史，但不能提前把想象中的变式当证据。
- 若首批变式暴露出比选定原句更完整的固定边界，可以修正原梗边界并留下变更记录。
- 变式少时，优先增加信息增益不同的查询，不重复同义搜索词凑次数。
- 模板越宽并非越好；目标是覆盖证据的最窄共同结构。
- 最终候选很差时，先定位是原梗适配性、模板、槽位契约还是回填策略的问题，不让自评分掩盖上游错误。

## AUTO 发现的诚实边界

过去的成功主管实验主要从模型已知的经典梗中主动挑选，再用搜索验证，例如：

- `你们不要再打了啦`
- `你有本事抢男人，你有本事开门啊`
- `别低头，皇冠会掉；别流泪，坏人会笑`
- `扶我起来，我还能送`

这证明了“已知候选后的主管处理能力”，尚未单独证明完全盲目的开放网络发现稳定可靠。新执行必须把“模型回忆候选”和“网络证据确认”明确分开，不得报告为同一种能力。

## 停止与人工干预

- 查不到真实严格变式：报告证据不足；AUTO 可换原梗，人工种子等待干预。
- 模板完整包审查失败：只自动修订一次；再次失败暂停。
- 生成候选无合格项：回到适用性或生成策略，不强行选出正式梗。
- 得到最终草稿后：必须等待结构化人工评价。持续执行开启时，也只能在评价提交并应用策略后开始下一轮。
