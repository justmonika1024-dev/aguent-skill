# 受控局部改写（`CONTROLLED_REWRITE`）

`CONTROLLED_REWRITE` 是 `STRICT_SLOT` 已完成真实变式验证和模板收敛后，直接槽位回填无法自然承载“某人凿 agu”时的生成回退。它不是新的证据类型，也不是自由改写许可：V/T 阶段仍按 `STRICT_SLOT` 执行，网络证据仍只证明真实模板；受控改写计划必须明确标为生成推断。

## 进入条件

仅当以下条件全部满足时进入：

1. O05 已核验完整原梗单元；
2. T09 已确认严格模板，T10-T12 的模板与槽位契约已经通过；
3. G01 确认现有槽位不能直接承载动作或事件，因此不能走 `STRICT_FILL`；
4. 模板中存在一个可替换的实体槽，且该实体在相邻固定文本中有可定位的共指代词、性质判断或行为判断；
5. 只需一次实体槽替换和一次与之绑定的局部谓词改写，就能建立“凿”施加于 agu 的关系。

模板证据不足、原梗边界未核验或需要改写多个分句时不得进入。`STRICT_SLOT` 失败本身不能推出 `CONTROLLED_REWRITE`。

## 允许的联动改写

先将已确认的实体槽替换为 `agu`，再只在与该槽共指的一个局部谓词范围内执行一种操作：

- `COREFERENCE_PREDICATE_INSERTION`：在共指代词前插入 `凿`，如 `你 → 凿你`；
- `COREFERENCE_PREDICATE_REPLACEMENT`：把描述该实体的一个性质或行为判断改为以 `凿` 为核心的谓词，并保持共指，如 `都是垃圾 → 都得凿他`。

两处表面变化若共同实现同一个实体到 agu 的语义映射，计为一次联动改写；不得借“联动”名义修改无关片段。

```yaml
generation_mode: CONTROLLED_REWRITE
edit_plan:
  entity_slot_replacements: 1
  linked_local_rewrites: 1
  new_clauses: 0
  deleted_clauses: 0
  reordered_clauses: 0
  operation: COREFERENCE_PREDICATE_INSERTION | COREFERENCE_PREDICATE_REPLACEMENT
  entity_slot_id: string
  coreference_span: string
  local_predicate_span_before: string
  local_predicate_span_after: string
  actor: string
  patient: agu
  preserved_anchors: []
```

## 改动预算和辨识度门禁

候选必须同时满足：

- 最多替换一个已验证实体槽；
- 最多改写一个与该实体直接共指的局部谓词范围；
- 不新增、删除或重排分句；
- 不改写反问、否定、递进、转折、时间强度、语气词等原梗骨架；
- 除已许可的两个范围外，其他固定文本逐字保留；
- `凿` 是新增或替换后的唯一核心内容谓词；允许加入维持语法所需的 `得/会/被/把/他/你` 等功能成分，但不得加入背景解释；
- agu 必须是受事者；施事者须能由原句主语或改写后的谓词明确确定；
- 单独读候选时仍能一眼识别原梗，不依赖标题解释。

字符数和编辑位置数不是单独的通过标准；审查对象是这些变化是否属于同一个必要语义映射。

## 节点

- `C01`：提出受控改写计划，输出共指链、许可范围、操作类型、施受角色和保留锚点；
- `C02`：生成候选，至少包含一条完全遵守预算的最小联动型，不得加入第二个笑点；
- `C03`：逐字对照原梗、模板和改写计划做硬审计。任何越界候选直接淘汰；全部淘汰则停止，不转入 `LONG_FORM`；
- 通过 C03 的候选复用 G04/G05 评分和选择，但额外评价“联动必要性”和“固定锚点保留度”。

## 校准

原梗：

```text
真是令人愉悦啊，五条悟，我大概一生都不会忘了你吧。
```

严格模板只证明人物槽可变。受控改写允许：

```text
五条悟 → agu
你 → 凿你
```

结果：

```text
真是令人愉悦啊，agu，我大概一生都不会忘了凿你吧。
```

这里 `agu` 与 `你` 共指，原句主语“我”是施事者，只有一个局部谓词插入，其他锚点不变。

原梗：

```text
我不是针对你，我是说在座的各位都是垃圾。
```

允许的最小联动方向：

```text
我不是针对agu，我是说在座的各位都得凿他。
```

`你 → agu` 与 `都是垃圾 → 都得凿他` 共同实现同一共指映射；“我不是针对”和“我是说在座的各位都”等辨识锚点、分句顺序和对照结构保持不变。

以下情况拒绝：

- 为解释高程群、同济大学或凿子新增一句背景；
- 同时改写开场、转折和结尾；
- 用“凿agu的人”“名叫凿agu的人”把事件伪装成人物称谓；
- 施事者不明或让 agu 主动凿别人；
- 严格回填本来就自然，却为了更花哨而转入本分支。
