# 领域定义与不可变规则

## 目标

产出中文纯文本文案梗：所有 AUTO 轮次先锁定有来源的完整原梗单元；`STRICT_SLOT` 保留其高辨识固定结构，以克制的槽位替换融入“某人凿 agu”；`LONG_FORM` 保留完整参照版本的可识别开场、反复、转折与结尾，允许有标记的必要改写，不自由另写故事。

## `凿agu` 的语义

- `agu` 是一个人。
- `凿` 是施加在 agu 身上的动作；`凿agu` 通常是动宾短语。
- 施事者可以是 `我 / 你 / 他 / 他们 / 群友 / 高程群群友` 等。
- 可选限定信息：`同济大学的`、`高程群的`，只有在句法、节奏或笑点确有帮助时才加入。
- `凿agu` 可以在适当语境中整体名词化或作主语，如“凿agu是一项……”，但不得因此忘记其底层仍表示动作事件。
- `凿agu` 表示必须保留的底层语义关系，不是必须连续出现的固定字符串。可按槽位句法实现为 `凿agu`、`agu被凿`、`agu的被凿`、`对agu的凿` 或带明确施事者的形式；无论表面形态如何，agu 都必须是“凿”的受事者。
- 模板中的研发方、发明方、实施方等角色，可以映射为执行 `凿agu` 的人，只要逻辑通顺。
- 不要求每个槽位都解释 `凿agu`；通常一个关键槽位承载核心事件已经足够。

## 内容范围

- 只处理中文纯文本；来源可以是网页、视频页、评论聚合页等，但证据只取其中可定位的文字。
- MVP 只使用公开搜索可发现内容；不绕过登录、验证码、付费墙或反爬限制。
- 模型常识可以用于提出搜索方向，不能作为传播度、原文或真实变式的证据。
- 原梗统一使用 [完整原梗单元](complete-meme-unit.md)；页面篇幅、字符数和模型熟悉度都不能单独证明边界完整。

## 严格槽位替换变式（`STRICT_SLOT`）

严格变式必须同时满足：

1. 与原梗共享可辨认的固定文本骨架；
2. 差异能解释为一个或多个连续槽位的替换；
3. 替换后仍是独立完整的同族句式；
4. 候选逐字存在于来源正文，可定位到 URL、标题和正文片段。

通常拒绝：只转载原句、释义、错别字、繁简差异、标点差异、单纯增加前后缀、删掉关键分句、同义改写、续写、回应原句、把两句拼接成新句、模型生成例子。

## 受控局部改写

`CONTROLLED_REWRITE` 只解决“严格模板已由真实变式确认，但现有槽位不能直接自然承载凿agu事件”的生成适配问题。它允许替换一个已确认实体槽，并在与该实体共指的一个局部谓词范围内执行一次必要联动；不得改变分句数量、顺序、主要语气和无关固定锚点。具体门禁见 [受控局部改写](controlled-rewrite.md)。

受控改写产物是生成推断，不得反向写入网络变式证据或扩大严格模板。

## 硬边界与软策略

硬边界不可被人工评分或策略学习覆盖：证据真实性、逐字可定位、正式梗查重、结构化人工评价阻塞下一轮；严格变式定义和一次模板自动修订上限仅适用于 `STRICT_SLOT`。`CONTROLLED_REWRITE` 不放宽这些证据门禁，只放宽已确认模板后的生成表层；`LONG_FORM` 的真实版本与推断编辑位边界见 [长梗改编](long-form-adaptation.md)。

软策略可以由反馈更新：优先数据源、查询组合、原梗结构偏好、候选数量、生成风格、评分权重、修饰信息使用频率。
